Why protons define the element

The number of protons is called the atomic number. Every carbon atom has exactly 6 protons; every oxygen atom has 8. Change the proton count and you change the element itself — and its chemical identity.

Ions vs. isotopes

An isotope has the usual number of protons but a different number of neutrons. An ion has an unequal number of protons and electrons, giving it a positive or negative charge. Both are still the same element.
