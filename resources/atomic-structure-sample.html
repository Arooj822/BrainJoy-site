Atomic structure: a five-question BrainJoy sample

Name or nickname: ____________________ Date: ______________

Use what you know about protons, neutrons and electrons. Try the questions before opening the answer guide.

  1. Which particle has a positive electric charge?
    A. Proton   B. Neutron   C. Electron
  2. An atom has atomic number 6. How many protons does it contain?
  3. True or false? Isotopes of an element have the same number of protons but different numbers of neutrons.
  4. A neutral atom contains 8 protons. How many electrons does it contain?
  5. What is the name of the negatively charged particle in an atom?
Teacher answer guide
  1. Proton. Protons carry a positive charge.
  2. 6. Atomic number is the number of protons.
  3. True. Changing the neutron count gives different isotopes of the same element.
  4. 8. A neutral atom has equal numbers of protons and electrons.
  5. Electron.
